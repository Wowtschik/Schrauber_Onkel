# OBD – Fehlerspeicher richtig interpretieren

Der OBD-Fehlerspeicher liefert Hinweise auf erkannte Abweichungen im Fahrzeug. Ein gespeicherter Fehlercode ist jedoch nicht automatisch die Ursache des Problems.

## Beispiel

Ein Fehlercode für einen Luftmassenmesser kann beispielsweise durch einen defekten Sensor, eine beschädigte Leitung, eine Undichtigkeit im Ansaugsystem oder ein anderes Problem verursacht werden.

## Vorgehensweise

Der Fehlercode sollte deshalb als Ausgangspunkt für die Diagnose betrachtet werden. Anschließend werden Messwerte und die tatsächlichen Betriebsbedingungen geprüft.

Erst daraus lässt sich eine belastbare Diagnose ableiten.
